# SW 수정 검토사항 — 1존 진행 현황

『AI 이동형 전시품 개발 SW 수정 검토사항』 PDF와 기획자 전달 사항의 1존(『지구를 위한 신재생 에너지』) 항목을 한곳에 모은 문서다. 다른 세션이나 에이전트가 이어서 작업할 때 이 문서부터 읽는다. 항목을 끝내면 상태와 관련 PR을 갱신한다.

- 원본 PDF: 저장소 루트 `AI 이동형 전시품 개발 SW 수정 검토사항.pdf` (1존은 1~6쪽, 공통 항목은 1쪽. 2~4존 쪽의 "모든 미션 동일 적용" 지적도 1존에 해당)

## 1. 기획자 전달 사항 (원문)

> - 미션 완료 성공 실패 구분하기 → 미션 성공/ 미션 실패
> - 블록 사용 사운드 추가( "동작/제어/논리/함수 블록을 사용해봐~")
> - 1존~4존 시작페이지 하단 "QR코드를 인식하여 주세요" ㅡ QR인식 ㅡ "시작하기를 눌러주세요" 통일
> - 인트로 페이지 "시작하기" 버튼 모두 제거하고 화면터치로 넘어가게 변경
> - "만약, 반복" -> 조건 / 조건안에 내용, 동작이 "제어"
> - [아침 8시] → 꺽쇠괄호 하고 랜덤 미션 텍스트 넣기 ( 그 외 랜덤 미션 창 변경값은 [ ] 으로 처리)
> - 결과 페이지 미션 처리 결과 표현 → 결과창 디자인 디벨롭 필요 (창 크기를 키우고 텍스트 정렬, 모델링 애니메이션 창 따로 만들기)
> - 1-3 수력댐 힌트창에 텍스트 추가
> - 1-3 결과창에 "수문 닫기 조건(아니면)" on off 추가 // 아니면 사용 안할시 표기해야 혼동 피함

## 4. 사용자 추가 요청·결정 사항

- **QR 스캐너**: SCP-8405(에스씨포인트) 예정. USB 키보드 입력 모드 기준으로 구현 — 연결된 모든 키보드를 구독하고 Enter 키 또는 CR/LF 문자로 인식 완료. 장치 분리·재연결 처리 (#56). 장치가 오면 스캔 끝 CR 설정, 한글 입력기 상태에서 값이 바뀌지 않는지 확인 필요.
- **스토리 난이도 표시**: "난이도 ★" 고정 이미지로 변경 (#56)
- **코딩 영역**: 스크롤바 제거, 빈 곳 드래그로 이동, 두 손가락 핀치·마우스 휠로 확대/축소(약 0.51~1.5배), 핀치 중에는 블록을 집지 못하고 집고 있던 블록은 제자리로 복귀 (#57)
- **결과 화면**: 확인 버튼 대신 AI 결과가 다 나오고 1초 뒤 "화면을 터치하면 다음으로 넘어갑니다" 안내 → 화면 터치로 완료 화면. 행이 5개인 레벨은 행 높이를 줄여 한 패널에 표시. 속도·대기 시간은 `StreamingAssets/Json/4_Result.json`에서 조정 (#59)
- **게임 씬 힌트 버튼**: "힌트" 유지
- **레벨4 채점**: 문제 문구(놀이시설은 잠시 끄고, 병원은 계속 켜기)상 병원 반복하기를 만약 밖에 둔 코드도 정답이라 반복하기 위치는 채점하지 않음. 놀이시설 불 끄기가 만약 안·병원 불 켜기가 반복 안이면 만점. 함정 동작 블록 '놀이시설 불 켜기'·'병원 불 끄기'를 쓰면 관련 항목 감점. 함정 조건 블록 '낮'·'전기 여유'(밤·전기 과부하의 반대)가 조건에 들어가면 조건 0점. 결과 '반복 감지' → '놀이시설 끄기 조건(만약)'. 무한 반복하기 뒤에 있어 실행되지 않는 놀이시설 불 끄기는 인정하지 않음(반복 안에서 만약으로 상황을 확인하는 코드는 인정)
- **빈 아니면**: 만약 안에 아니면을 놓고 아래를 비우면 컴파일 에러(아니면 블록 빨간 점멸). 만약·반복하기 안이 비었을 때와 같은 규칙
